# frontend

> **스택 미정.** 팀이 정하면 이 폴더에 프론트엔드 프로젝트를 만든다.
> 화면과 흐름은 `docs/기획/아이디어_v4.md`(3장 서비스 흐름, 4장 청년센터 상세, 9장 MVP·데모 시나리오)가 기준이다.

## 맡는 일

- 모바일 웹 화면 (휴대폰 세로 화면 기준)
- 백엔드 API 호출 (API 목록·요청/응답 형식: `backend/README.md`)
- 브라우저 기능: 위치(GPS 도착 확인), 사진 선택(선택 기능), 카카오맵

## 화면 목록 (MVP)

| 화면 | 핵심 요소 |
| ---- | --------- |
| 시작 질문 | 질문 3개(활동 범위 / 부담 상황 / 혼자·함께) → 시작 별자리 제안 → 선택 |
| 밤하늘 (홈) | 내 별자리, 아직 따지 않은 별·희미한 별·딴 별, 바로 위 단계 열기 |
| 체크인 | 한 줄 일기 + "오늘은 어떤 활동이 괜찮을까요?" → 마음 날씨("AI가 고른 날씨예요. 다르면 바꿔 주세요") |
| 오늘의 별 | 추천 별 1~3개 + 이유, 바깥 별은 근처 장소 |
| 별 수행 | **"하늘의 별 따기"** / **"손 뻗어 보기"** 버튼, GPS 별은 도착하면 버튼이 켜짐, `직접 도착 기록` |
| 회고·다음 행동 | 회고 한 줄 → 응원, (손 뻗어 보기면) 이유 선택 → 더 작게 / 다른 날 / 다른 별 / 마치기 |
| 별자리 완성·도감 | 완성 연출, 별을 누르면 그날의 기억(날짜 + 회고) |
| 바깥 지도 | 근처 청년센터, 참여 부담별 정책 (단계와 관계없이 언제든) |
| 청년센터 상세 | `문의 문장 준비하기` · `앞까지 가 보기` 나란히, 초안 저장 |
| 도움받을 곳 | 109, 1577-0199, 지역 청년마음건강 지원사업 (항상 접근 가능) |

## 주의할 점

- **API 응답의 `help`가 있으면 항상 안내를 띄운다** (위기 표현 감지 결과)
- `checkinId`가 `null`이면 "저장하지 못했어요" 안내 + 재시도, 입력 내용은 유지
- 위치·카메라는 **HTTPS 또는 localhost**에서만 동작 (시연: 노트북 개발자 도구 모바일 화면 + 위치 지정)
- 위치 권한 거부·실패 시 바로 `직접 도착 기록`으로 전환, 불이익·다른 연출 없음
- 별 개수·점수·순위를 화면에 강조하지 않음 (기획 원칙)
- 카카오맵 JS 키는 브라우저에 노출되므로 카카오 개발자 콘솔에 도메인 등록 필요
