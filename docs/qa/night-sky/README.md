# 밤하늘 UI·UX 검증 결과

기준 `master`는 `c928731`, 최종 기능 확인 커밋은 `2ffd9bd`다. Chrome 예시 모드에서 첫 방문과 기록이 쌓인 세션을 나눠 확인했다. 모바일 화면은 320×568과 390×844, 데스크톱 키보드 검사는 1440×900을 사용했다.

## 기능별 확인

| 기능 | 확인 커밋 | 시작 상태와 조작 | 직접 확인한 결과 |
| --- | --- | --- | --- |
| 양자리 튜토리얼 | `5aa8856` | 첫 방문 → 데모 시작 → 양자리 안내 → 별 네 개 따기 | 별을 따야 다음 별로 진행한다는 안내와 별마중 획득 흐름이 일치한다. |
| 작은 화면 상단 버튼 | `12dfb03` | 온보딩을 마친 밤하늘 → 음악 오른쪽 가장자리, 청년센터·정책 왼쪽 가장자리 차례로 누르기 | 320px에서도 음악 상태가 바뀌고 정책 메뉴가 각각 열린다. [320px 화면](fix01-header-320.png) |
| 키보드 탐색 | `aba385d` | 데스크톱 밤하늘 → Tab으로 주요 메뉴 이동 → 별 목록에서 Enter → Esc → 다시 열기 | 개별 별보다 별 목록·하늘 지도·오늘의 별에 먼저 닿는다. 목록을 열 때마다 닫기 버튼에 초점이 가고, Esc를 누르면 별 목록 버튼으로 돌아온다. [목록 초점](fix02-list-focus-desktop.png) |
| 별자리 완료 문구 | `24a194a` | 양자리만 완성한 밤하늘 → 하늘 지도 → 양자리 | 전체 화면에는 ‘별자리 1개를 이었어요’, 양자리 상세에는 ‘양자리를 이었어요’가 표시된다. [양자리 상세](fix03-aries-320.png) |
| 사진 교체와 응원 문구 | `bc8fb7b` | 별 기록 → 사진 선택 → 사진 바꾸기 → 사진 빼기. 두 결과를 각각 저장 | 기존 사진을 먼저 삭제할 필요 없이 교체할 수 있다. 예시 모드에서 ‘하늘의 별 따기’와 ‘손 뻗어 보기’의 저장 후 응원 문구가 구분된다. [사진 조작](fix04-photo-controls-320.png) |
| 청년센터 조회 오류 | `b094173` | 검증 세션에서 센터 요청 실패 재현 → 청년센터 열기 | ‘센터 정보를 불러오지 못했어요. 잠시 후 다시 시도해 주세요.’가 표시된다. [오류 화면](fix05-center-error-390.png) |
| 캐릭터 크기와 말풍선 복귀 | `2ffd9bd` | 오늘 미저장, 친구 선택 → 밤하늘에서 캐릭터가 사라질 때까지 드래그 → 천천히 복귀 → 빠르게 왕복 | 선택한 친구의 크기에 맞춰 말풍선이 머리 위에 자리 잡은 뒤 캐릭터가 나타난다. 320×568과 390×844 모두 캐릭터가 보이는 프레임의 최소 간격은 약 8px, 겹침은 0프레임이었다. [지면](quest-ground-320.png) · [하늘](quest-air-320.png) |
| 오늘의 별 저장 여부 | `2ffd9bd` | 오늘 미저장 → 하늘에서 말풍선 누르기 → 저장 전 닫기 → 다시 열어 ‘마음 날씨 보기’로 저장 → 닫기·새로고침 | 저장 전에는 하늘에서도 말풍선으로 다시 열 수 있다. 저장 후에는 같은 날 새로고침해도 말풍선이 숨겨지고, 지면에서는 캐릭터를 눌러 다시 열 수 있다. [저장 후](quest-saved-320.png) |

## 전체 흐름에서 함께 살펴본 화면

| 흐름 | 조작 및 관찰 범위 |
| --- | --- |
| 처음 방문·오늘의 별 | 시작 질문, 양자리 별 네 개와 첫 친구 획득, 오늘의 별 입력과 추천 별에서 기록 진입 |
| 밤하늘 탐색 | 별 목록의 별자리·난이도 보기, 목록에서 고른 별 강조, 하늘 지도, 친구 도감 |
| 기록 다시 보기 | 프로필에서 별 일기 사진 필터와 별자리별 기억 앨범 재생. 날짜별 일기와 별자리별 앨범의 진입 이름·배치는 팀 논의 사항 |
| 보상·꾸미기 | 별빛 상점의 잔액 부족 표시, 아이템 착용, 밤하늘에서 착용 상태 확인 |
| 정책·청년센터 | 정책 추천 기준, 신청 도우미, 청년센터 상세와 오류 안내 |
| 마음 짚기·도움 안내 | 질문, 응답 요약, 결과 및 도움 안내 화면 확인 |
