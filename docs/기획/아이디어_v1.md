
# 1차 핵심 기능 기획 회의록

## 1. 타겟 사용자

- **주요 타겟:** 사회적 관계 형성에 어려움을 겪는 은둔·고립 청년

**(+ 확장 타겟:** 일상에 새로운 동기와 목표를 얻고 싶은 일반 사용자(갓생러 등))

## 2. 핵심 기능 개요

- 사용자의 심리적 부담 수준을 파악하고, 이에 맞는 단계별 사회화 퀘스트 제공
- 퀘스트 수행 여부를 인증하고, 완료한 퀘스트를 도감에 기록하는 시스템 구현

## 3. 주요 서비스 이용 흐름

### ① 심리 검사 및 단계 설정

- UCLA 외로움 척도 + Mini-SPIN 점수 산출
- 검사 결과를 바탕으로 사회적 활동에 대한 부담 수준을 Lv.1~4로 구분
- **'나의 마음 날씨' 리포트 제공**
  - 검사 결과를 점수로만 보여주는 대신 날씨에 비유해 직관적으로 표현
  - 사용자의 현재 심리 상태와 부담 수준 시각화

### ② 퀘스트 선택 및 제공

- 별자리를 테마로 퀘스트 구성
  - 예: 오리온자리, 전갈자리, 북두칠성 등
- 별자리별로 약 7단계의 퀘스트 제공
- 사용자가 원하는 별자리를 선택하고 단계별 퀘스트 수행
- 심리적 부담 수준에 따라 적절한 난이도의 퀘스트 제공

### ③ 퀘스트 수행 및 인증

퀘스트 유형에 따라 서로 다른 인증 방식 적용

| 퀘스트 유형    | 인증 방식                |
| -------------- | ------------------------ |
| 산책하기       | GPS 위치 및 이동 기록    |
| 카페 방문하기  | 영수증 인증              |
| 영화 관람하기  | 예매 내역 또는 인증 사진 |
| 기타 외부 활동 | 사진 등 활동 증빙        |

- 퀘스트별 적절한 인증 방식을 적용해 실제 수행 여부 확인

### ④ 퀘스트 완료 및 도감 수집

- 퀘스트 인증 완료 시 해당 퀘스트 완료 처리
- 완료한 퀘스트를 도감에 등록
- 별자리별 진행 상황 및 수집 현황 확인

## 4. 추가 논의 및 확장 가능성

- 데일리 체크인 검사 ⇒ 정보 업데이트
- 사용자 활동 이력과 심리적 반응을 반영한 퀘스트 개인화
- 초기 타겟인 은둔·고립 청년에서 일반 사용자까지 타겟 확장 가능성 검토
- 별자리별 퀘스트를 단계적으로 완성하는 수집형 콘텐츠 구조 구체화
