# 나란히 기능 완료 기준과 화면 문구

11월 19일 개발용 문구안. 첫 통합의 종착점은 같은 브라우저에서 별을 다시 눌러 방금 쓴 회고를 읽는 순간이다. 아래는 인수 기준이며, 현재 코드와 실행 증거는 [소개서 07](../제출/프로젝트소개서_원고.md)에 구분한다.

## 돌아온 이유와 이어갈 선택

“어디에서 발걸음이 멈췄나요?” 이유는 선택 사항이다. 아래 문구와 괄호 안 DB 값을 짝지어 쓴다.

| 고르는 이유 | 다음 제안 예시 |
| --- | --- |
| 사람이 많았어요 (crowded) | “다음에는 한산할 때 입구까지만 가볼까요?” |
| 날씨·상황이 안 맞았어요 (weather) | “날이 괜찮은 날 같은 별을 다시 만나볼까요?” |
| 몸이나 마음이 힘들었어요 (tired) | “다음에는 현관문만 잠깐 열어봐도 좋아요.” |
| 시간이 없었어요 (no_time) | “시간이 나는 날 같은 별을 다시 골라도 돼요.” |
| 나랑 안 맞았어요 (not_for_me) | “비슷한 거리에서 다른 활동을 찾아볼까요?” |
| 돈이 들어서요 (cost) | “돈이 들지 않는 다른 활동을 골라볼까요?” |
| 다른 이유가 있어요 (other) | “여기서 마칠까요, 다음에 해볼 일을 고를까요?” |

버튼은 **더 작게 해 보기**(smaller) / **다른 날 그대로 하기**(retry) / **다른 별로 바꾸기**(swap) / **여기서 마치기**(stop). 사용자가 고른 선택을 저장한다. AI 응원이 늦거나 실패하면 bright에는 “오늘 해낸 일을 이 별에 담았어요.”, dim에는 “오늘 손을 뻗어 본 순간을 이 별에 담았어요.”를 쓴다. 저장 성공 뒤에만 이 문구를 보여준다.

## 시연에서 고를 수 있는 별

아래 이름·순서는 db/init/02_seed.sql 기준이다 (별자리 10개 · 별 30개, 더미 콘텐츠). API에서 받은 별 ID로 기록한다. 난이도는 별자리마다 랜덤으로 한 번 뽑아 고정했고, 별 수 = 난이도(1단계만 3개)다. 괄호는 집 안 외 확인 방식·종류.
