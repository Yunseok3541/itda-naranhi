## 1. 문제 정의

### 문제

- 고립·은둔 청년은 **도움받을 곳이 있어도 거기까지 가는 첫 걸음을 떼기 어렵다**
- 청년센터, 심리상담 바우처, 청년정책 같은 지원은 이미 있지만 대부분 **직접 신청하거나 방문해야** 이용할 수 있음
- 즉, 지원이 가장 필요한 사람이 지원에 가장 접근하기 어려운 구조

### 근거 (2026-11-23 출처 확인, 고민기록 #62)

- **규모:** 국무조정실 「2024년 청년의 삶 실태조사」(2025.3 발표): 거의 집에만 있는 **은둔 청년이 19~34세의 5.2%**. 한국보건사회연구원·한국경제인협회 보고서는 이를 바탕으로 **약 53만 8천 명**으로 추산 (2022년 조사 2.4%, 약 24만 4천 명에서 두 배 이상)
  - 발표 문구: "은둔 청년 약 54만 명(19~34세의 5.2%, 2024년 청년의 삶 실태조사 기반 추산)"
  - ⚠ 예전에 쓰던 "2022년 조사, 고립·은둔 약 5%, 약 54만 명"은 정의가 섞인 숫자라 쓰지 않음. 2023년 기사들이 2022년 조사로 "최대 54만 명"이라 보도했지만 보건복지부는 이를 경미한 위험 징후까지 포함한 최대 추정치라고 설명했고, 같은 2022년 조사에서 "은둔"만 보면 2.4%
- **벗어나고 싶은 마음:** 보건복지부 「2023년 고립·은둔 청년 실태조사」(2023.12 발표, 19~34세 응답자 21,360명 중 위험군 12,105명): **80.8%가 현재 상태에서 벗어나고 싶다**고 응답, **4명 중 3명 이상이 자살을 생각한 적이 있다**고 응답 (고립 기간이 길수록 높음)
  - ⚠ 자살 생각 비율을 "75.4%"로 쓴 기사와, 75.4%를 대학 졸업 비율로 쓴 기사가 섞여 있어 숫자 대신 "4명 중 3명 이상"으로 씀. 이 조사는 참여 신청자 대상이라 전체 청년 비율이 아님
  - 출처(기사): 세계일보 2025.3.11 「2022년 2.4%서 5.2%로 급증」, 뉴시스 2025.3.11 「2024년 청년의 삶 실태조사」, 뉴시스 2026.4.24 「53만 청년, 평생 고립 우려」, 뉴시스·서울신문 2023.12.13 (복지부 2023 실태조사). 국무조정실·복지부 원문 보도자료는 발표 자료에 넣기 전 한 번 더 열어 볼 것
- → **"벗어나고 싶지만 방법과 첫 걸음이 없다"**가 이 서비스가 해결하려는 지점

### 페르소나 (가상)

> **민수(26세)**, 취업 실패 후 2년째 대부분 방에서 지냄
> - 바뀌고 싶은 마음은 있지만 "청년센터 방문"은 너무 먼 이야기
> - 습관 앱을 깔아봤지만 연속 기록이 끊기면 자책하고 삭제
> - 필요한 것: **실패해도 괜찮은, 아주 작은 첫 걸음**과 **그다음 걸음을 알려주는 누군가**

### 제공 가치

1. 지금 할 수 있는 만큼의 아주 작은 행동부터 시작
2. 실패해도 흔적이 남고, AI가 더 작은 걸음으로 다시 제안
3. 단계가 오르면 실제 지원(청년센터, 정책, 봉사)으로 이어지는 출구

## 2. 핵심 컨셉 (v2 유지)

> **지향점: 언젠가 필요 없어지기를 바라는 앱**
> 마지막 별자리(청년센터 프로그램, 봉사 참여)를 완성한 사용자가 더 이상 이 앱을 열지 않아도 되는 것이 목표

- **별 하나 = 퀘스트 하나**, 별을 모으면 별자리 완성
- 레벨은 내부에서만 사용, 사용자에게는 "카시오페이아자리부터 시작해볼까요?"로 표현
- 6단계 (집 안 → 집 앞 → 혼자 외출 → 사람 있는 곳 → 짧은 상호작용 → 대화·참여)
- 별 밝기: 꺼진 별 / 희미한 별(시도) / 밝은 별(완료), 실패에 대한 불이익 없음
- 아래 단계는 언제든 이동 가능, 위 단계는 현재 별자리를 완성해야 열림
- **같은 하늘의 별:** 다른 사용자들의 별을 누구 것인지 모르게 밤하늘에 희미하게 표시하고, "오늘 '현관 앞 5분 서 있기'를 18명이 시도했어요"처럼 모은 숫자만 보여줌 → 대화 없이 "나만 그런 게 아니구나"를 전달 (고민기록 #14)

## 3. 서비스 흐름 (AI 반영)

```
[최초 1회]
심리 검사(단축형 UCLA + Mini-SPIN) → 레벨 산출(비공개) → 마음 날씨 리포트 + 시작 별자리 선택
                                                        └ AI⑤ 지금 단계에 맞는 정책 추천

[매일 반복]
① 체크인 한 줄      ─AI②→ 마음 날씨 갱신 ─AI③→ 위험 신호 감지
        ↓
② 오늘의 별 추천    ─AI①→ 상태·기록에 맞춰 선택, 실패한 별은 더 작게 쪼개기
        ↓
③ 별 수행 → 인증 → 회고 한 줄 ─AI④→ 맞춤 응원 (+ 다음 추천에 반영) ─AI③→ 위험 감지
        ↓
④ 별자리 완성       → 도감 등록, 다음 단계 열림 ─AI⑤→ 새 단계에 맞는 정책 추천
```

- 첫 레벨 판정은 **검증된 척도**가 맡고, **매일의 변화**는 AI가 맡음

## 4. AI 기능

> AI의 역할: 짧게 듣고 오늘의 별을 골라 주는 동반자 (가칭 "별지기")
> 상담사가 아님. 길게 대화하지 않고, 필요한 순간에는 전문기관으로 연결

### ① 오늘의 별 추천 + 실패한 별 쪼개기 (핵심)

| 항목 | 내용 |
| ---- | ---- |
| 입력 | 현재 단계, 별 기록(희미한 별·밝은 별), 오늘의 마음 날씨, 최근 회고 |
| 출력 | 오늘 추천할 별 1~3개 + 추천 이유 한 줄 |
| 쪼개기 | 희미한 별이 생기면 같은 목표를 더 작은 퀘스트로 나눠 제안 |
| 예시 | "카페에 10분 앉아 있기" 실패 → "카페 앞까지 가서 메뉴판만 보고 오기" |
| 왜 AI인가 | 사람마다 막히는 지점이 달라서 고정된 퀘스트 목록으로는 대응할 수 없음 |

### ② 체크인 → 마음 날씨 갱신

| 항목 | 내용 |
| ---- | ---- |
| 입력 | 한 줄 일기 ("오늘 좀 피곤해요") |
| 출력 | 날씨(맑음 / 구름 / 흐림 / 비 등), 오늘의 권장 난이도 |
| 연결 | 흐린 날에는 ①에서 아래 단계의 쉬운 별 추천 |
| 왜 AI인가 | 매일 설문을 반복하면 이탈. 자유 문장에서 상태를 읽어야 부담이 적음 |

### ③ 위험 신호 감지

| 항목 | 내용 |
| ---- | ---- |
| 입력 | 체크인, 회고 문장 |
| 출력 | 위험 여부 (정상 / 주의 / 위험) |
| 대응 | 주의·위험이면 "혼자 감당하지 않아도 돼요" + 자살예방상담전화 109, 지역 청년마음건강 지원사업 안내 |
| 방식 | 키워드 규칙 + AI 판단 함께 사용 |

### ④ 회고 맞춤 응원

| 항목 | 내용 |
| ---- | ---- |
| 입력 | 별 수행 결과(밝은 별·희미한 별) + 회고 한 줄 |
| 출력 | 회고 내용을 구체적으로 짚는 한두 문장 응원 |
| 원칙 | 희미한 별에도 응원 / 과장된 칭찬과 "다음엔 ~해보세요" 같은 지시 금지 / 짧게 |
| 예시 | 희미한 별 + "현관까지 갔다가 들어왔어요" → "현관까지 나간 것도 별 하나만큼의 일이에요" |
| 연결 | 회고 내용은 ①의 다음 추천에 반영 |

### ⑤ 단계별 정책 추천

| 항목 | 내용 |
| ---- | ---- |
| 처리 | 정책·복지서비스 수집 → 규칙 필터(나이, 지역, 모집 상태) → **AI가 참여 부담 분류**(온라인 / 전화 / 방문 / 집단 참여) + 쉬운 말 요약 → 사용자 단계에 맞춰 추천 |
| 노출 위치 | 마음 날씨 리포트, 별자리 완성 시 |
| 왜 AI인가 | API에 "이 정책이 얼마나 부담스러운가"라는 값이 없음. 설명 문장을 읽고 판단해야 함. 키워드 필터는 관련 없는 정책이 섞임 |
| 퀘스트화하지 않음 | 정책은 탈락·자격 미달·마감처럼 통제할 수 없는 결과가 있어 좌절 위험. 추천까지만 함 (고민기록 #7) |

### 구현 방식

- 모든 AI 출력은 **정해진 JSON 형식**으로 받아 앱이 검증 후 사용
- 정책 분류는 **미리 배치로 한 번만** 실행해 저장 (사용자 요청마다 호출하지 않음)
- ①②③④는 사용자 입력 시 호출, 작은 모델 우선 사용

## 5. AI 한계와 대응

| 기능 | 한계 | 대응 |
| ---- | ---- | ---- |
| ① 별 추천 | 엉뚱하거나 너무 어려운 퀘스트 생성 | 단계별로 미리 정한 퀘스트 범위 안에서만 고르고 쪼개도록 제한, 범위 밖이면 기본 퀘스트로 대체 |
| ② 마음 날씨 | 짧은 문장으로 상태를 잘못 읽음 | 날씨는 추천 난이도에만 영향, 사용자가 직접 날씨를 고칠 수 있게 함 |
| ③ 위험 감지 | 위험 신호를 놓침 | 키워드 규칙과 병행, 애매하면 안내를 보여주는 쪽(더 안전한 쪽)으로 처리 |
| ④ 응원 | 부적절하거나 상처 주는 문장 | 프롬프트로 톤·길이 제한, 금지 표현 필터, 실패 시 미리 써둔 기본 응원 문구 |
| ⑤ 정책 분류 | 분류 오류, 요약 중 사실 왜곡 | 자격은 규칙으로 판단, 애매하면 더 높은 단계로 분류, 원문 링크 항상 표시 |
| 공통 | API 장애·지연 | 기본 문구·기본 퀘스트로 대체해 흐름이 끊기지 않게 함 |
| 공통 | 검사·날씨를 진단으로 오해 | "진단이 아님" 안내 유지 |

## 6. 차별성

| 구분 | 예시 | 한계 | 우리 서비스 |
| ---- | ---- | ---- | ----------- |
| 습관·챌린지 앱 | 챌린저스, 루티너리 | 이미 의욕 있는 사람 대상, 연속 기록·벌금 등 실패에 불이익 | 심리 상태에 맞는 시작점, 실패도 희미한 별로 남음 |
| 셀프케어 게임화 앱 | Finch 등 | 앱 안에서 끝남, 실제 사회 연결 없음 | 단계가 오르면 청년센터·정책·봉사로 이어짐 |
| 심리상담 앱 | 마인드카페, 트로스트 등 | 상담을 시작하는 것 자체가 부담 | 상담 이전 단계의 작은 행동부터, 필요하면 상담으로 연결 |
| 공공 지원사업 | 청년센터, 청년마음건강 지원사업 | 직접 신청·방문해야 해서 은둔 청년이 닿기 어려움 | 그 지원까지 가는 길을 단계별로 만들어 줌 |

**핵심 차별점 한 줄:** 지원까지 가는 **첫 걸음부터 마지막 걸음까지**를 AI가 사람에 맞춰 설계해 주고, 실패해도 다시 작게 시작할 수 있게 한다.

## 7. 안전장치와 개인정보

### 안전장치 (v2 + AI)

- 검사·날씨는 진단이 아님을 안내
- Lv.1 사용자에게 전문기관 연계를 부드럽게 안내
- 1단계 첫 별은 실패할 수 없을 만큼 쉬운 퀘스트
- 매일 체크인·회고에서 위험 신호 감지 (AI ③)
- 결과를 통제할 수 없는 정책은 퀘스트로 만들지 않음

### 개인정보

- 심리검사 결과, 체크인·회고 문장은 **민감정보**로 취급
- 수집 시 목적을 알리고 동의를 받음, 필요한 것만 저장
- AI에 보낼 때 이름 등 개인 식별 정보는 제외
- GPS는 인증 순간에만 사용하고 이동 경로 전체는 저장하지 않음
- 사용자가 언제든 기록을 삭제할 수 있게 함
- 같은 하늘의 별: 이름·캐릭터·정확한 위치 미표시(구 단위 이상), 5명 미만이면 숫자 숨김, 완료율·순위 없이 시도 수만 표시, 집계 포함 여부는 사용자가 선택

## 8. 효과 측정 지표

| 구분 | 지표 | 측정 방법 |
| ---- | ---- | --------- |
| 심리 변화 | 외로움·사회불안 점수 변화 | 4주마다 단축형 척도 재검사 |
| 행동 변화 | 단계 상승률, 외출 퀘스트(3단계 이상) 완료 수 | 별 기록 |
| 지속성 | 희미한 별 이후 다시 시도한 비율, 주간 체크인 횟수 | 별·체크인 기록 |
| AI 효과 | 쪼갠 별의 완료율 (원래 별 대비) | 별 기록 |
| 실제 연결 | 청년센터 방문·프로그램 참여 퀘스트 완료율, 추천 정책 원문 확인 비율 | 퀘스트·클릭 기록 |

- 발표에서는 **"쪼갠 별의 완료율"**과 **"실제 지원으로 연결된 비율"**을 대표 지표로 제시

## 9. 운영·비용·확장

### 운영 주체

- **1차: 지자체·청년센터 보급형 (B2G)**
  - 청년센터는 은둔 청년을 찾아내고 연결하기 어려움 → 이 앱이 청년센터까지 오는 길을 만들어 줌
  - 사용자 동의 시 청년센터와 단계 정보 연계 검토
- **2차: 일반 사용자 확장** (갓생러 등)
  - 별자리 테마 추가, 일상 목표형 퀘스트

### 비용 구조

| 항목 | 방식 |
| ---- | ---- |
| AI 호출 | 사용자당 하루 3회 내외(체크인, 추천, 응원), 작은 모델 사용 |
| 정책 분류 | 배치로 한 번만 처리 후 저장, 정책 갱신 시에만 재분류 |
| 공공 API | 무료 공공데이터 활용, 결과 캐싱 |
| 지도 | 지오코딩 결과 저장해 재사용 |

### 발전 방안

- 활동 이력 기반 퀘스트 개인화 고도화
- 영수증 OCR, GPS 인증
- 1365 봉사 연계 퀘스트
- 청년센터 담당자용 화면 (동의한 사용자의 단계 확인)

## 10. 해커톤 MVP 범위

| 꼭 구현 | 여유 있으면 |
| ------- | ----------- |
| 단축형 심리 검사 → 마음 날씨 리포트 | 영수증 OCR, GPS 인증 |
| 1단계 별자리 2개 + 2단계 별자리 1개 | 1365 봉사 연계 퀘스트 |
| 자기 보고 또는 사진 인증 | 청년센터 담당자용 화면 |
| | 같은 하늘의 별 (데모 시 "예시 데이터" 표시) |
| 별 점등(희미한 별·밝은 별), 별자리 완성 연출, 도감 | |
| **AI ① 오늘의 별 추천 + 실패한 별 쪼개기** | |
| **AI ② 체크인 → 마음 날씨 갱신** | |
| **AI ③ 위험 신호 감지** | |
| **AI ④ 회고 맞춤 응원** | |
| **AI ⑤ 단계별 정책 추천** | |
| 내 주변 청년센터 지도 | |

### 데모 시나리오

1. Lv.1 사용자 검사 → 마음 날씨 "흐림" + 전문기관 안내 + 집에서 신청 가능한 정책 추천 (AI ⑤)
2. 카시오페이아자리 선택 → 첫 별 "창문 열고 하늘 보기" 완료
3. 다음 날 체크인 "오늘 좀 무기력해요" → 날씨 갱신 (AI ②) → 쉬운 별 추천 (AI ①)
4. "현관 앞 5분 서 있기" 실패 → 희미한 별 → 회고 "현관까지 갔다가 들어왔어요" → 응원 (AI ④)
5. AI가 "현관 문 열고 30초 서 있기"로 쪼개 제안 (AI ①) → 성공 → 밝은 별
6. 별자리 완성 → 다음 하늘이 열림 → 새 단계에 맞는 정책 추천 (AI ⑤)
7. (보조) 체크인에 위기 표현 입력 → 109 안내 화면 (AI ③)

- 보조 연출: 같은 정책 데이터를 **키워드 필터 결과 vs AI 분류 결과**로 나란히 보여주기
- 데모용 AI 응답과 API 결과는 백업 데이터로 저장 (네트워크 장애 대비)
