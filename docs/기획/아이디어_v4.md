## 1. 문제 정의 (v3 유지 + 대표 사용자 구체화)

- 고립·은둔 청년은 **도움받을 곳이 있어도 거기까지 가는 첫 걸음을 떼기 어렵다**
- 지원(청년센터, 심리상담 바우처, 청년정책)은 대부분 직접 신청하거나 방문해야 이용할 수 있음
- 근거 수치는 v3 1장 (⚠ 출처 확인 필요)

### 페르소나 (가상)

> **민수(26세)**, 취업 실패 후 2년째 대부분 방에서 지냄
> - 바뀌고 싶은 마음은 있지만 "청년센터 방문"은 너무 먼 이야기
> - **근처에 청년센터가 있다는 건 알지만, 전화하거나 문을 여는 순간이 무섭다**
> - 습관 앱을 깔아봤지만 연속 기록이 끊기면 자책하고 삭제
> - 필요한 것: **실패해도 괜찮은 아주 작은 첫 걸음**, 그리고 **문의·방문 같은 문턱을 같이 넘어 줄 도움**

### 제공 가치

1. 오늘 할 수 있는 만큼, **내가 고른** 작은 행동부터 시작
2. 시도도 흔적으로 남고, 어려웠다면 AI가 더 작은 걸음으로 다시 제안
3. 원할 때 언제든 실제 지원 정보를 보고, 문의·참여의 문턱을 낮추는 도움을 받음

## 2. 핵심 컨셉

> **지향점: 언젠가 필요 없어지기를 바라는 앱**
> 사용자가 앱 밖의 활동과 사람에게 이어져 더 이상 앱을 열지 않아도 되는 것이 목표

### 원칙: 사용자가 고른다

- 시작 단계, 오늘의 활동 범위, 마지막 별자리, 참여 여부는 **사용자가 정함**
- AI 판단(날씨, 추천)은 언제든 바꿀 수 있는 **제안**
- 검사 점수로 사람을 나누지 않음

### 구성

- **별 하나 = 퀘스트 하나**, 밤하늘의 별을 따서 내 별자리에 담고, 다 담으면 별자리 완성 → 도감
- 6단계: 집 안 → 집 앞 → 혼자 외출 → 사람 있는 곳 → 짧은 상호작용 → 대화·참여 (단계 숫자는 화면에 노출하지 않음)
- 같은 단계 안에 테마가 다른 별자리 2~3개 → 사용자가 선택
- **단계 이동:** 아래 단계는 언제든, **바로 위 단계 하나는 직접 열 수 있음**. 별자리를 완성하면 다음 하늘이 자연스럽게 열림
- **마지막 별자리:** 청년센터 프로그램 / 봉사 / 원데이클래스·소모임 중 선택, 또는 **`지금은 여기까지`**. 그동안 모은 별자리는 그대로 남고, 원할 때 다시 이어갈 수 있음 (외부 참여를 원하지 않는 사용자에게도 실제 선택지가 됨)
- 별 상태: 아직 따지 않은 별 / **시도한 별**(희미함) / 딴 별(밝음). 실패에 대한 불이익 없음

### 하늘의 별 따기 (고민기록 #22)

> 아주 어려운 일을 "하늘의 별 따기"라고 한다. 집 앞에 나가는 것도 누군가에겐 그만큼 어려운 일일 수 있다.

| 버튼 | 언제 | 결과 |
| ---- | ---- | ---- |
| **하늘의 별 따기** | 스스로 정한 목표를 해냈을 때 (GPS 별은 도착하면 버튼이 켜짐) | 밝은 별을 따서 내 별자리에 담음 |
| **손 뻗어 보기** | 시도했지만 끝까지 하지 못했을 때 | 희미한 별로 남음. 손을 뻗은 것도 기록 |

- **별에 담기는 기억:** 별자리·도감에서 별을 누르면 그 별을 딴 날짜와 회고 한 줄을 보여줌
  - 예: "11월 20일 · 오랜만에 공원까지 걸었어요"
  - 숫자·포인트 없이 기록이 개인의 기억으로 남음
  - ⚠ 이름만 바꾸고 희미하게 남으면 여전히 실패 표시로 읽힐 수 있음 → 팀에서 결론 내리지 않고 **사용성 테스트로 확인**. "부담스럽나요?"가 아니라 설명 없이 별을 보여 주고 **"이 별은 어떤 뜻으로 보이세요?"**라고 물어 실제로 어떻게 읽히는지 확인. 실패로 읽히면 테두리·모양으로 구분하는 안 검토
- **같은 하늘의 별:** 다른 사용자의 시도를 익명 집계로만 표시 (v3 유지, MVP는 여유 있으면)


### 다시 찾게 되는 이유 (별 모으기 말고 실질적인 가치)

1. **"오늘 뭘 하지?"를 정해 준다:** 한 줄 체크인과 오늘 선택만으로 지금 할 수 있는 한 가지가 나옴
2. **어려웠던 것을 기억하고 다음을 바꿔 준다:** 습관 앱처럼 처음부터 다시 시작하지 않고, 돌아온 이유에 맞춰 다음 행동이 달라짐
3. **"뭐라고 말하지?", "어디 가지?"를 도와준다:** 문의 문장 초안과 근처 갈 만한 장소

- 알림은 넣더라도 **기본 꺼짐**, 연속 기록을 압박하지 않는 문구만 (여유 있으면)
- 처음 들어오는 경로는 앱 기능이 아니라 운영의 문제 → v3 9장 운영 주체(청년센터·지자체가 직접 닿기 어려운 청년에게 안내) 참고

### 차별점 (고민기록 #25)

> **어려웠던 이유를 듣고 다음 행동을 다시 찾아, 실제 장소와 사람에게 이어 간다.**

- 별자리·추천·응원 같은 개별 기능이 아니라 이 **전체 경험**으로 차별성을 설명
- v3 6장의 경쟁 서비스 비교표는 근거를 확인하기 전에는 발표에 쓰지 않고, 쓰더라도 단정적인 표현은 피함

## 3. 서비스 흐름

```
[처음 1회]
시작 질문 3개 → 시작 별자리 제안 → 사용자가 별자리 선택
  ① 요즘 할 수 있는 활동 범위는? (집 안 / 집 앞 / 혼자 외출 / 사람 있는 곳)
  ② 부담되는 상황은? (사람 만나기 / 낯선 곳 / 전화·대화 / 아침에 일어나기 …, 복수 선택)
  ③ 혼자 하고 싶은가, 다른 사람과의 활동도 알아보고 싶은가?
  시작 질문을 저장하면 양자리 안내로 이어짐. 마음 짚기는 프로필에서 원하는 때 시작 (아래 "마음 짚기" 참고)

[매일 반복]
① 체크인: 한 줄 일기 + "오늘은 어떤 활동이 괜찮을까요?"(쉬어 가기/집 안/집 근처/바깥)
      ─AI②→ 마음 날씨 제안(참고, 수정 가능)  ─AI③→ 위기 표현 시 도움받을 곳 안내
        ↓
② 오늘의 별 추천 ─AI①→ 오늘 선택·부담 상황·별 기록·회고로 1~3개 추천, 바깥 별은 근처 장소까지 제안
        ↓
③ 별 수행 → 확인(집 안: 자기 보고 / 바깥: GPS 도착, 못 쓰면 자기 보고)
   → "하늘의 별 따기" 또는 "손 뻗어 보기" → 회고 한 줄
      ─AI④→ 맞춤 응원  ─AI③→ 위기 표현 감지
   → (손 뻗어 보기였다면) 이유 선택: 사람이 많았어요 / 날씨·상황이 안 맞았어요 / 몸·마음이 힘들었어요 / 시간이 없었어요 / 나랑 안 맞았어요 / 돈이 들어서요 / 기타
      ─AI①→ 이유에 맞는 다음 행동 제안 → 사용자가 선택
            · 더 작게 해 보기 (예: 사람이 많았다 → 사람 적은 시간에 앞까지만)
            · 다른 날 그대로 하기 (예: 갑자기 비가 왔다 → 같은 별을 다른 날에)
            · 다른 별로 바꾸기 (예: 카페가 돈이 들어서 → 비슷한 난이도의 도서관·공원)
            · 여기서 마치기 (희미한 별로 남기고 끝)
        ↓
④ 별자리 완성 → 도감 등록, 다음 하늘이 열림 (별을 누르면 그날의 기억)

[언제든]
· 바깥 지도: 근처 청년센터·정책 정보 ─AI⑤→ 참여 부담별로 정리된 정책
· 청년센터 상세 화면 (4장) — 첫날 지도에서 바로 들어와도, 별자리 완성 후 추천받아 들어와도 같은 화면
· 도움받을 곳: 109, 정신건강위기상담 1577-0199, 지역 청년마음건강 지원사업
```

### 마음 짚기 (선택, 고민기록 #56·#57)

> 구현 경로는 프로필 → "마음 짚기" (`/mind-check`). 질문은 한 화면에 하나씩 보여 주고, 별 세 개로 현재 묶음을 표시한다 (고민기록 #57). 질문은 건너뛸 수 있고 한 묶음 이상 모두 답했을 때 저장할 수 있다. 결과는 문장으로 보여 주고 마음 짚기 화면에서 다음 권장일을 안내한다.

> 예시 모드는 묶음별 점수와 기록 시각을 이 브라우저에 저장한다. 실제 모드는 `GET·POST /api/mind-check`로 질문별 응답과 점수를 저장한다. 기존 운영 DB에서는 `db/migrations/20261124_mind_check.sql`을 적용하고 `/api/health`의 `mindCheck`가 `ready`인지 확인한다.

> 시작 질문·체크인에는 점수를 매기지 않는다. 검증된 척도는 **4주마다 하는 선택형 마음 짚기에만** 모은다.

| 구분 | 언제 | 내용 | 점수 |
| ---- | ---- | ---- | ---- |
| 시작 질문 | 처음 1번 | 지금 그대로 (활동 범위 등 3~6개) | 없음. 답으로 시작 단계를 정함 |
| **마음 짚기 (선택)** | 프로필에서 원하는 때 시작, 4주 간격으로 비교 권장 | UCLA 3문항 + LSNS-6 + WHO-5 (14문항, 2~3분) | 있음. **변화 측정용**, 단계·위험 판정에 쓰지 않음 |
| 체크인 | 매일 (원할 때) | 지금 그대로 (한 줄 + 오늘 선택 + 마음 날씨) | 없음 |

| 척도 | 문항 | 재는 것 | 넣는 이유 |
| ---- | ---- | ------- | --------- |
| UCLA 3문항 | 3 | 외로움 (주관) | 기존 유지 |
| LSNS-6 | 6 | 실제 관계망 (가족·친구 중 연락·도움 주고받는 사람 수) | "앱 밖 사람과 이어졌나"를 직접 잼 |
| WHO-5 | 5 | 지난 2주 마음 상태 | 낮으면 상담받을 곳 안내 (PHQ-2 역할 대신). 2주 회상이라 4주 간격과 겹치지 않음 |

- **결과 화면:** 점수 숫자보다 변화 문장 ("지난번보다 연락하는 사람이 늘었어요"). "진단이 아니에요" 안내 유지
- **쓰지 않는 것:** Mini-SPIN(사회불안장애 선별 도구라 진단처럼 읽힘, 시작 질문 ②와 겹침, 사용 허락 필요로 알고 있음), PHQ-2(WHO-5와 역할 겹침, 위기 순간에 끼우면 도움 안내가 늦어짐), 체크인에 WHO-5 1문항씩 돌리기(5문항 묶음이라 한 문항 값은 의미 없음, 매일 설문은 "매일 안 와도 돼요" 원칙과 충돌)
- ⚠ 확인 필요: UCLA·LSNS-6 사용 조건, 세 척도의 한국어판 출처 → `제출/외부자원과_출처.md`
- **DB:** `survey_results.spin_score` → `lsns_score`, `who5_score` (마이그레이션 필요, `answers`는 JSONB 그대로)

## 4. 청년센터 상세 화면 (지원까지 가는 경험)

운영시간이나 예약 필요 여부를 알아야 집을 나설 수 있는 사람도 있고, 일단 앞까지 가 보고 싶은 사람도 있다. 그래서 **정해진 순서 없이 한 화면에서 고른다.** 단계와 관계없이 언제든 들어올 수 있다.

```
[청년센터 상세]  ○○구 청년센터
  운영시간 · 위치 · 연락처 · 프로그램(참여 방식·대상·준비물, AI ⑤ 요약)

  [ 문의 문장 준비하기 ]   [ 앞까지 가 보기 ]

  참여했어요 (직접 기록)
```

| 행동 | 앱이 돕는 것 | 기록 방식 |
| ---- | ------------ | --------- |
| **문의 문장 준비하기** | **AI ⑥**이 궁금한 점(예약 없이 가도 되는지, 처음인데 괜찮은지 등)을 문의 메시지·전화 대본 초안으로 정리. **초안만 저장하고 끝내도 됨** | 초안 저장. 실제로 문의했다면 사용자가 "문의해 봤어요"로 직접 기록 |
| **앞까지 가 보기** | 센터 위치로 안내, 들어가지 않아도 됨 | **GPS 도착 → "앞까지 가 본 별"이 켜짐.** 위치를 쓰지 않으면 같은 화면의 **`직접 도착 기록`** → 같은 별, 같은 연출 |
| **참여** | 참여 여부는 사용자가 정함. 안 해도 아무 기록이 남지 않음 | 사용자가 직접 기록 (선택) |

- **GPS가 켜는 별은 "앞까지 가 본 별" 하나뿐.** 센터 근처에 있었다고 문의·참여까지 기록하지 않음 → 지표가 섞이지 않음
- 조회·문의·참여는 서로 다른 기록. 앞의 것만 했다고 뒤의 것을 한 것으로 보지 않음

## 5. AI 기능

> AI의 역할: 짧게 듣고 오늘의 별을 골라 주는 동반자 (가칭 "별지기")
> 상담사가 아님. AI 판단은 언제든 사용자가 바꿀 수 있는 제안

| # | 기능 | 입력 → 판단 → 달라진 제안 | 왜 AI인가 |
| - | ---- | ------------------------- | --------- |
| ① | **오늘의 별 추천 + 시도한 별 다음 행동** (핵심) | 같은 "손 뻗어 보기"라도 이유에 따라 다른 제안: "사람이 많아서 돌아왔어요" → `더 작게 해 보기`(사람 적은 시간에 앞까지만) / "갑자기 비가 와서 돌아왔어요" → `다른 날 그대로 하기` / "카페는 돈이 들어서요" → `다른 별로 바꾸기`(근처 공원·도서관). "센터 앞까지 갔는데 문을 열기 어려웠어요" → "다음에 가기 전에 예약 없이 들러도 되는지 물어볼 문장을 같이 준비할까요?"(⑥으로 연결). 오늘 선택·부담 상황으로 근처 장소까지 제안. (여유 있으면) 바깥 날씨가 비면 가까운 실내 장소도 함께 제안, 선택은 사용자에게 | 사람마다 막히는 지점이 달라 고정 목록으로 대응할 수 없음 |
| ② | **체크인 → 마음 날씨 제안** | 한 줄 일기 → 날씨 하나 제안 (참고 기록, 언제든 수정) | 매일 설문을 반복하면 이탈. 자유 문장에서 상태를 읽어야 부담이 적음 |
| ③ | **위기 표현 안내** | 체크인·회고 문장 → 위기 표현이 보이면 도움받을 곳 안내. 키워드 규칙(직접·간접 2단계) + AI, 더 위험한 쪽 채택 | 간접 표현은 규칙만으로 놓치기 쉬움 |
| ④ | **회고 맞춤 응원** | 시도 결과 + 회고 → 회고 내용을 짚는 한두 문장 응원. 시도한 별에도 응원, 지시·과장 금지 | 회고마다 다른 내용을 짚어야 응원이 전해짐 |
| ⑤ | **정책 참여 부담 분류** | 정책 설명 → 참여 방식(온라인/전화/방문/집단) + 쉬운 말 요약. 미리 배치로 분류해 저장 | API에 "얼마나 부담스러운가"라는 값이 없음 |
| ⑥ | **문의 문장 초안** (신규) | 센터·프로그램 정보 + 사용자가 궁금한 점(또는 ①이 회고에서 읽은 부담) → 문의 메시지·전화 대본 초안. 초안 저장만 해도 됨, 보내기는 사용자가 직접 | 상황마다 문장이 달라야 하고, "뭐라고 말하지?"가 가장 큰 문턱 |

### 구현 방식 (v3 유지)
- 모든 AI 출력은 정해진 JSON 형식으로 받아 검증 후 사용, 실패하면 기본값
- 정책 분류는 미리 배치로 한 번만 실행해 저장
- 오늘의 별 추천은 하루 한 번 생성해 저장 (날씨를 고쳐도 다시 만들지 않음. 날씨가 난이도를 정하지 않기 때문)

## 7. 안전장치와 개인정보

### 안전장치
- 마음 짚기·날씨는 진단이 아님을 안내
- 마음 짚기 WHO-5가 낮으면(원점수 13점 미만) 결과 화면에 상담받을 수 있는 곳 안내. 점수로 단계·위험을 정하지 않음
- **"도움받을 곳" 메뉴를 항상 표시** (109, 1577-0199, 지역 청년마음건강 지원사업)
- 체크인·회고에서 위기 표현이 보이면 안내 (AI ③)
- 첫 별은 실패할 수 없을 만큼 쉬운 퀘스트
- 결과를 통제할 수 없는 정책·참여는 퀘스트 성공 조건으로 만들지 않음
- 안내를 본 것과 실제 상담·참여는 구분해서 기록·설명

### 개인정보
- 시작 질문 답, 마음 짚기, 체크인·회고 문장은 **민감정보**로 취급, 목적을 알리고 동의
- AI에는 이름 등 식별 정보 없이 문장만 전송
- **GPS:** 도착 확인 순간에만 읽음, 이동 경로·좌표·집 위치는 저장하지 않고 "도착함"과 장소 ID만 기록. 위치 권한은 바깥 퀘스트를 처음 시작할 때 이유와 함께 요청
- 사진은 선택
- 사용자가 언제든 기록 삭제
- 같은 하늘의 별: 익명, 구 단위 이상, 5명 미만 숨김, 참여는 선택

## 8. 효과 측정 지표 (고민기록 #25)

별을 모으는 것, 외출을 시도하는 것, 지원 정보를 확인하는 것, 실제로 참여하는 것은 서로 다른 성과다. 나란히가 **가장 먼저 만들고 싶은 변화는 "첫걸음"**이므로 시도를 기준으로 삼는다.

### 1순위 지표

> **앱 밖 활동을 시도한 사용자 비율**
> 바깥 별(GPS 별 포함) 또는 청년센터 행동(앞까지 가 본 별, 문의, 참여 기록)을 한 번이라도 **시도한** 사용자 / 전체 사용자. `손 뻗어 보기`도 시도로 셈

- 완료·참여가 아니라 시도를 세는 이유: 해결하려는 문제가 "첫걸음을 떼기 어렵다"이고, 원칙이 "시도를 인정한다"이기 때문

### 보조 지표

| 구분 | 지표 | 보는 이유 |
| ---- | ---- | --------- |
| AI 효과 | 손 뻗어 보기 이후 다음 행동(더 작게·다른 날·다른 별)을 고른 뒤 **다시 시도한 비율** | AI가 이유에 맞춰 다음 행동을 바꾼 것이 실제로 도움이 됐는지 |
| 지원 연결 | 청년센터 행동별 기록 수 (상세 보기 / 문의 문장 준비 / 앞까지 가 본 별 / 문의 기록 / 참여 기록) | 순서를 강제하지 않으므로 퍼널이 아니라 행동별로 집계 |

### 참고로만 보는 값

| 값 | 주의 |
| -- | ---- |
| 모은 별 개수 | **목표 지표로 쓰지 않음** (쉬운 별만 많이 모아도 커짐) |
| 마음 날씨 조정 비율 | AI 정확도로 해석하지 않음 |
| 정책 원문 열람 | "정보 확인"이지 참여가 아님 |
| 마음 짚기 4주 변화 (외로움 UCLA-3 · 관계망 LSNS-6 · 마음 상태 WHO-5) | 선택 응답이라 전체 대표성 없음. LSNS-6 변화는 1순위 지표(앱 밖 활동)를 뒷받침하는 참고값 |
| "여기서 마치기"·"지금은 여기까지" 비율 | 실패가 아니라 정상적인 선택. 급증하면 퀘스트 난이도 점검 신호로만 사용 |

- 시연 데이터는 실제 효과가 아님을 화면과 발표에서 명시 ("예시 데이터")

## 9. 해커톤 MVP 범위

| 꼭 구현 | 여유 있으면 |
| ------- | ----------- |
| 시작 질문 3개 → 시작 별자리 제안·선택 | 선택형 마음 짚기 |
| 1단계 별자리 2개 + 2단계 별자리 1개 | 같은 하늘의 별 ("예시 데이터" 표시) |
| 체크인(한 줄 + 오늘 선택) + 날씨 수정 | 청년센터 담당자용 화면 |
| "하늘의 별 따기"·"손 뻗어 보기" 버튼, 별자리 완성 연출, 도감, 바로 위 단계 열기 | **바깥 날씨**(기상청 단기예보) → 바깥 별 추천 참고 + 아이콘 (1순위) |
| **별을 누르면 그날의 기억**(날짜 + 회고) | 1365 봉사 연계 |
| **GPS 도착 확인** (2단계 "편의점 다녀오기", 센터 "앞까지 가 본 별") + `직접 도착 기록` | 사진 기록 |
| **시도한 별 다음 행동**: 이유 선택 + `더 작게 해 보기` · `다른 날 그대로 하기` · `다른 별로 바꾸기` · `여기서 마치기` | 가벼운 알림 (기본 꺼짐) |
| **청년센터 상세 화면**: `문의 문장 준비하기` · `앞까지 가 보기` 나란히, 초안 저장 | |
| 마지막 별자리 선택의 `지금은 여기까지` (화면 문구 수준) | |
| "도움받을 곳" 메뉴 | |
| 바깥 지도: 근처 청년센터 + 정책(참여 부담별) | |
| **AI ①~⑤**, **AI ⑥ 문의 문장 초안** | |

### 데모 시나리오

> 중심 장면: **"센터 앞까지 갔는데 문을 열기는 어려워서 돌아왔어요"** — 별을 모으는 재미, 사용자의 선택권, AI가 다음 행동을 조정하는 이유가 한 번에 드러남 (고민기록 #24)

1. 시작 질문: "집 근처까지는 괜찮아요 / 사람 만나기가 부담 / 혼자" → 별자리 제안 → 선택
2. 첫 별 "창문 열고 하늘 보기" → **"하늘의 별 따기"** → 첫 별을 땀
3. 다음 날 체크인 "오늘은 좀 나가 볼까 싶어요" + 오늘 선택 "바깥" → 날씨 제안 (AI ②) → 추천에 "청년센터 앞까지 가 보기" 포함 (AI ①)
4. 지도에서 근처 청년센터 → **상세 화면**: 운영시간·프로그램 요약 (AI ⑤) + `문의 문장 준비하기` / `앞까지 가 보기`
5. **중심 장면:** `앞까지 가 보기` → GPS 도착(또는 `직접 도착 기록`) → "하늘의 별 따기" → **앞까지 가 본 별** → 회고 "앞까지 갔는데 문을 열기는 어려워서 돌아왔어요" → 응원 (AI ④)
6. AI가 부담을 느낀 순간을 반영해 **"다음에 가기 전에, 예약 없이 들러도 되는지 물어볼 문장을 같이 준비할까요?"** (AI ①) → 문의 문장 초안 (AI ⑥) → **초안만 저장하고 오늘은 마침**
7. **마무리:** 별자리에서 그 별을 누르면 "11월 20일 · 청년센터 앞까지 갔어요" → 그날의 기억
8. (보조) 같은 "편의점 다녀오기" 손 뻗어 보기에 이유만 다르게: "사람이 많아서" → `더 작게 해 보기` 제안 / "비가 와서" → `다른 날 그대로 하기` 제안 / "돈이 들어서" → `다른 별로 바꾸기`(근처 공원) 제안 (AI ①이 답에 따라 제안을 바꿈)
9. (보조) 체크인에 위기 표현 입력 → 도움받을 곳 안내 (AI ③)

- 보조 연출: 같은 정책 데이터를 **키워드 필터 결과 vs AI 분류 결과**로 나란히 보여주기
- 시연: 노트북 모바일 화면(개발자 도구로 위치 지정). 휴대폰으로 실제 걷는 시연이 필요하면 고정 HTTPS 주소(Vercel + Neon) 검토

## 10. 남은 과제

- [ ] 시작 질문 3개의 문구, 답 → 시작 단계 대응 규칙
- [ ] "오늘 선택" 4가지 문구와 추천 범위
- [ ] 별자리·퀘스트 확정, GPS 별 목록과 목표 장소 종류, `더 작게 해 보기`용 하위 퀘스트
- [ ] 마지막 단계 별자리 후보 (청년센터 프로그램 / 봉사 / 원데이클래스·소모임)
- [ ] 청년센터 상세 화면, AI ⑥ 프롬프트, 센터 별 콘텐츠(앞까지 가 본 별 등) 시드 데이터
- [ ] 손 뻗어 보기 이유 선택지 문구, 이유별 다음 행동 제안 규칙, `다른 별로 바꾸기`용 같은 난이도 대체 별 목록
- [ ] 알림 문구 (연속 기록 압박 없이, 기본 꺼짐)
- [ ] 마음 날씨 종류와 문구, "도움받을 곳" 화면 문구
- [ ] 희미한 별 사용성 테스트: 설명 없이 별을 보여 주고 "이 별은 어떤 뜻으로 보이세요?"
- [ ] 별 따기 연출(별이 하늘에서 내 별자리로 옮겨지는 애니메이션), 기억 카드 화면
- [ ] (여유 있으면) 기상청 단기예보 API 키 신청, 위경도 → 격자 좌표 변환
- [ ] 위험 표현 테스트 문장 30개 → **초기 테스트 결과**로 제시 (직접·간접·부정문·타인 이야기·AI 실패 포함)
- [ ] 문제 근거 수치 출처 확인 (v3 1장). 경쟁 서비스 비교표(v3 6장)는 근거 확인 전에는 발표에 쓰지 않음
- [ ] 대회 규칙 확인 (URL 제출 여부 → 배포 결정)
- [ ] 제출물에 "이전 안에서 바뀐 점"(포인트·경험치·스몰톡 제외, 검사 → 시작 질문) 정리
