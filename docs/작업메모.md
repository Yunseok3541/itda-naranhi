## 2. 다른 컴퓨터에서 이어서 시작하기

```bash
git clone https://github.com/Yunseok3541/itda-naranhi.git
cd itda-naranhi
docker compose up -d           # DB (Docker Desktop 필요, 저장소 루트에서. 없으면 Neon 개발용 DB)
cd web
npm install
cp .env.example .env.local     # GEMINI_API_KEY 등 입력
npm run dev                    # http://localhost:3000/api/health → "db":"ok" 확인
```

- `.env.local`(API 키)은 git에 없음 → 새 컴퓨터에서 다시 입력
- Docker 없이 하는 방법(Neon 개발용 DB)과 배포 순서는 `web/README.md` 참고

## 4. 확인이 필요한 문제

- **ERDCloud 한글 표시:** `COMMENT`가 논리명으로 들어가지 않았음. 컬럼 상세의 코멘트 항목에 들어갔는지 확인 필요. 안 들어갔으면 논리명은 직접 입력
- **Gemini 무료 등급:** 입력이 Google 서비스 개선에 쓰일 수 있음 → 실제 개인정보 입력 금지, 테스트 데이터만
- **스키마 수정 시:** 루트 `db/init/01_schema.sql`(실제)과 `db/erdcloud.sql`(확인용)을 함께 수정. 이미 만든 DB는 루트에서 `docker compose down -v && docker compose up -d`로 다시 생성 (⚠ `-v`는 기존 데이터를 모두 지움. 데이터를 남기려면 바뀐 컬럼·뷰만 `ALTER TABLE`, `CREATE VIEW`로 추가)
