```

 └─ fix/main-screen-fixed     메인 화면 고정 (태그 sky-v0 = 배경 작업 시작점)
```

배경 관련 파일
- `web/src/app/sky-preview/sky-panorama.tsx`: 배경 그리기 (메인·첫 화면·`/sky-preview`가 함께 씀)
- `web/src/lib/sky-view.ts`: 배경과 별자리가 함께 쓰는 시점(어디를 얼마나 크게 보는지)·투영 계산 (2단계부터)
- `web/src/lib/sky-constellations.ts`: 앱 별자리 → 실제 별 좌표·선. **별자리에 퀘스트를 더하거나 빼면 여기 좌표 수도 맞춰야 함** (안 맞으면 빈 하늘에 임시 호 모양으로 그려짐) (2단계부터)
- `web/src/components/night-sky.tsx`·`night-sky.css`: 퀘스트 별·이름표·선 (2단계부터 고정 무대 대신 하늘 위에)
- `web/public/sky/celestial.json`: 별·은하수 데이터 (만드는 법: `web/scripts/build-celestial-data.mjs`)
- `web/public/sky/LICENSE-d3-celestial.txt`: 데이터 라이선스 (BSD-3, 지우지 않는다)
- 예전 배경 이미지 `web/public/sky-preview/panorama.webp`는 1단계부터 쓰지 않지만 되돌리기 쉽게 남겨 둠

## 2. 왜 천구 뷰인가 (결정 이유 요약)

- 무료 배포(Vercel)에서는 서버 비용보다 **내려받는 용량·휴대폰 성능·개발 시간**이 문제
- 천구 뷰는 큰 이미지·3D 라이브러리 없이 Canvas 2D로 그림 → 데이터 약 27KB(압축), 예전 배경 이미지(375KB)의 약 7%
- 위치·카메라 권한 없음. 실제 별 위치라 앱 별자리를 실제 하늘과 이어 줄 수 있음
- 비교했지만 고르지 않은 것: 스카이 돔·스카이박스(3D 엔진 필요), 360도 구형 파노라마(큰 이미지·WebGL), 플라네타리움(위치 정보·무거운 엔진), AR 스카이맵(카메라·센서 권한, 배경에 부적합)

## 4. 복구 가이드

### 먼저 할 것 (모든 상황 공통)

```bash
git status                 # ① 지금 브랜치와 저장 안 한 변경 확인
git fetch origin --tags    # ② GitHub의 최신 기록·태그 받기
git log --oneline -15      # ③ 최근 단계 목록 (위가 최신)
git tag -l "sky-*"         # ④ 태그 목록
```

- `git status`에 바뀐 파일이 보이면 먼저 정리: 남길 거면 커밋, 잠깐 치워 둘 거면 `git stash` (다시 꺼내기: `git stash pop`)
- 단계 찾기: `git log --oneline --grep "배경 1단계"`
- 이동한 뒤 화면이 이상하면 `cd web && npm install` 후 `npm run dev`. 브라우저는 새로고침

### 상황별 방법

| 하고 싶은 것 | 명령 | 비고 |
| ------------ | ---- | ---- |
| **A. 한 단계만 취소** (기록 남음, 가장 안전) | `git switch feat/sky-background` → `git revert <해시>` → `git push` | 편집기가 뜨면 저장 후 닫기 (vim: `:wq`). 충돌 시 파일 고치고 `git add <파일>` → `git revert --continue`, 포기는 `git revert --abort` |
| **B. 예전 단계 잠깐 보기** | `git switch --detach sky-v0` → 확인 → `git switch feat/sky-background` | "detached HEAD" 안내는 정상. 이 상태에서 커밋하지 않기 |
| **C. 예전 단계에서 다른 방향으로** (추천) | `git switch -c feat/sky-background-b sky-v0` → `git push -u origin feat/sky-background-b` | 두 버전 모두 보관 |
| **D. 브랜치를 예전 단계로 되돌림** (뒤 단계 버림, 주의) | `git tag backup-<날짜>-1` → `git push origin backup-<날짜>-1` → `git reset --hard sky-v0` → `git push --force-with-lease` | 먼저 백업 태그. 되살리기: `git reset --hard backup-<날짜>-1` → `git push --force-with-lease`. **master에는 절대 하지 않기** |
| **E. 배경 작업 통째로 그만두기** | `git switch fix/main-screen-fixed` 또는 `git switch master` | 브랜치는 GitHub에 남아 있음 |
| **F. 실수로 날린 것 같을 때** | `git reflog -20` → `git switch -c rescue <찾은 해시>` | 리셋 전 상태도 reflog에 남아 있음 |

### 터미널 없이

- **GitHub 웹**: 브랜치 `feat/sky-background` → Commits 에서 단계별 변경 보기, Tags 에서 `sky-vN` 시점 코드 보기
- **VS Code**: 소스 제어 패널 → 그래프(GRAPH)에서 커밋 오른쪽 클릭 → `Checkout (Detached)`(=B), `Create Branch...`(=C), `Revert Commit`(=A)
- 병합된 PR 되돌리기: GitHub PR 화면 맨 아래 **Revert** 버튼

### 하지 말 것

- `git add -A` / `git add .` → 비밀값 파일이 같이 올라갈 수 있음. 바꾼 파일만 이름으로 `git add`
- API 키·DB 주소는 `web/.env.local`(앞에 점)에만
- `master`에 `reset`·`--force` 푸시
- `web/public/sky/LICENSE-d3-celestial.txt` 삭제 (데이터 라이선스 조건)
