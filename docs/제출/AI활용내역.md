# AI 활용내역

## 홈페이지 입력 원고 · 3,000자 이내

① 활용 AI 모델·도구

서비스에는 Google Gemini API를 연결하는 서버 코드를 작성했습니다. 현재 코드에서 체크인 한 줄로 마음 날씨와 위험 신호를 제안합니다. 개발 과정에서는 OpenAI Codex를 사용해 저장소와 공식 양식을 대조하고 기획·시연·제출 문서 초안을 작성했습니다.

② AI 활용 범위와 팀의 기여

팀은 오늘 활동 범위를 사용자가 선택하는 방식, 목표에 닿기 전의 시도도 기록하는 두 버튼, 센터 도착과 실제 문의를 별도로 기록하는 기준을 정했습니다. Codex는 이 결정을 화면 문구와 인수 기준으로 정리했습니다. 서비스 안에서 모델은 문장을 받아 구조화된 응답을 제안하고, 서버 코드는 허용값을 검사하고 위험 표현 규칙과 결합합니다.

③ API·외부 데이터·오픈소스

Next.js와 React로 화면과 API를 구성하고, Google Gen AI SDK로 서버에서 모델을 호출합니다. PostgreSQL 스키마와 팀의 예시 시드에는 별자리 3개와 별 16개가 있습니다. 청년센터·정책 데이터 연계는 계획 단계입니다. 상세 버전과 출처는 소개서 지정 별첨에 기재합니다.

④ 검증 및 한계 대응

현재 코드에는 AI 호출이나 출력 검증이 실패하면 기본 날씨를 쓰고, 위험 규칙을 재평가하며, 체크인 저장에 실패해도 안내를 응답하는 경로가 있습니다. 날씨는 사용자가 수정할 수 있습니다. 문서 작성 시 저장소에서 이 처리 분기를 대조했습니다. 배포본의 모델 응답, 회고 저장, 모바일 시연 결과는 실제로 재현한 범위만 최종본에 반영합니다.
