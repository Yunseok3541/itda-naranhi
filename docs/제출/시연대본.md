# 심사위원 시연 대본

목표 시간 2분 30초(시작 안내 포함). URL은 윤석이 로그아웃 브라우저로 확인한 주소를 07장에 넣는다. 가상 입력만 사용하고, 재희는 실제 API에 연결한 화면을 캡처한다. 예시 모드는 개발 리허설용으로 표시한다.
> 2026-11-22 최신 화면 기준으로 고침: 시작 질문(별 카드), 시작 안내(양자리 별 4개 → 별마중), 메뉴 안내, 오늘의 별은 메인 아래 캐릭터를 누름, 마음 짚기. 별자리를 고르는 단계는 없음(시작 질문 답으로 정해짐).
> 실제 API 모드에서 양자리 안내가 나오려면 공용 Neon에 `20261124_constellation_shapes.sql`이 적용돼 있어야 함(2026-11-22 적용 확인). 적용 전이면 "연습 별자리"로 기록 없이 진행됨.

| 순서 | 누를 곳과 가상 입력 | 심사위원에게 보여줄 변화 | 캡처 |
| --- | --- | --- | --- |
| 1 | 새 브라우저 → **데모 시작** → 시작 질문 ① "어디까지 편하게 다닐 수 있어요?" 집 근처 → **다음** → ② "어떤 게 부담돼요?" 사람 만나기 → **다음** → ③ "활동은 어떻게 해 보고 싶어요?" 혼자 하고 싶어요 → **저장하고 시작하기** | 가능한 범위를 사용자가 직접 정한다. 모든 질문은 건너뛸 수 있다. | A 시작 질문 |
| 2 | 시작 안내 → **첫 별 따러 가기** → **하늘의 별 따기** 4번(날씨는 "구름 조금", 한 줄은 "창밖이 생각보다 밝았어요") → 별마중 모달 **계속하기** → **다음** → **다음** → **내 밤하늘 열기** | 실패할 수 없는 첫 별 4개로 양자리를 완성하고, 친구 별마중을 도감에서 만난다. 딴 별은 실제 기록으로 남는다(40P). | B 별마중 모달 |
| 3 | 메뉴 안내 → **다음**으로 버튼 7개를 차례로 비추며 한 줄씩 소개 (시간이 부족하면 Esc) | 도움받을 곳은 항상 위쪽 모서리에 있다. 버튼 이름과 하는 일이 바로 보인다. | — |
| 4 | 메인 아래 **캐릭터**(오늘의 별) 누르기 → 마음에 떠오른 한 줄 "오늘은 집 근처까지는 나갈 수 있을 것 같아요." → 오늘의 활동 범위 **집 근처** → **다음** → 마음 날씨 확인(다르면 날씨 칸을 눌러 바꾸기) → **오늘의 별 추천받기** → ("마음 짚기도 해 볼래요?"가 뜨면 **나중에 할래요**) → 추천 이유를 읽고 '집 근처 산책로 한 바퀴 돌기' → **이 별 만나기** | 날씨와 오늘 선택이 따로 보이고, 추천이 오늘 선택과 연결된다. 리허설에서 이 별이 없으면 실제 추천된 집 근처 별로 진행하고 회고도 그 행동에 맞춘다. | C 제목·추천 이유 |
| 5 | **손 뻗어 보기** → 어떤 점이 어려웠나요? **몸·마음이 힘들었어요** → 오늘을 기억할 한 줄 "산책로 입구까지만 가 봤어요." → **이 순간 저장하기** → "오늘의 순간을 담았어요" 아래 **다음에 이어볼 별** 제안(실제 API: 더 작게 해 보기·다른 날 그대로 등)을 보여 주고 **오늘은 여기서 마칠래요** | 목표를 다 채우지 않아도 시도가 기록되고, 어려웠던 이유에 맞춰 다음 걸음을 제안한다. 예시 모드에서는 "기존 별에서 다음 행동 찾아보기"만 보이므로 이 장면은 실제 API로 촬영한다. | D 두 버튼·기록 결과 |
| 6 | **내 밤하늘** → 브라우저 새로고침 → 방금 손 뻗어 본 별 누르기 | 별이 희미하게 남아 있고, 날짜와 방금 입력한 원문을 다시 읽을 수 있다. | E 새로고침 후 별과 회고 |

발표 멘트 — "오늘은 집 근처까지 나가 볼 수 있다고 했습니다. 산책로 입구까지 갔지만 한 바퀴를 채우지는 못했어요. 내일 앱을 다시 열었을 때도 오늘 어디까지 가 봤는지가 남고, 다음엔 더 작은 걸음을 제안합니다."

## 후속 장면 · 센터 앞에서 돌아온 날

1. 오른쪽 위 **청년센터·정책** → **청년센터** → 시연용 센터의 **센터 자세히 보기**. 실데이터면 출처·기준일, 가상이면 '예시 데이터'가 함께 보이는지 확인한다.
2. 센터 상세의 '앞까지 가 보기' 묶음에서 **앞까지 가 본 별 기록하기**를 누른다(별 기록 화면으로 이동). 별 기록에서 **하늘의 별 따기**, 한 줄 "센터 앞까지 갔는데 문을 열기는 어려웠어요."를 남기고 **이 순간 저장하기**. 센터 앞까지 간 별이 켜진다. 문의나 프로그램 참여 횟수가 늘어나면 수정한다.
3. **문의 문장 준비하기** → 궁금한 점에 "처음인데 예약 없이 들러도 되나요?" → **문의 초안 준비하기**.
4. 초안(예: "안녕하세요. 처음 방문하려고 하는데 예약 없이 들러도 될까요?")을 확인하고 **초안만 저장하기**에서 끝낸다. F 캡처는 센터의 두 선택지(문의 문장 준비하기·앞까지 가 보기), G는 저장된 초안이다. 장소·운영시간·문의 전송을 꾸며내지 않는다.

## 선택 장면 · 마음 짚기 (시간이 남을 때)

아래 왼쪽 **프로필** → **마음 짚기** → 묶음별로 답하고 저장. 4주마다 외로움·곁에 있는 사람·마음 상태를 짚어 보는 선택 기능이며, 진단이 아니라 변화를 보는 기록이라는 점을 함께 말한다.
