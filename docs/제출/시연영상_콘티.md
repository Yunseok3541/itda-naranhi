# 시연 영상 콘티

선택 제출 영상(3분 이내, 소개서 07장)용. 목표 길이 2분 45초. 누를 곳과 가상 입력은 [시연 대본](시연대본.md)과 같고, 이 문서는 장면별 시간, 자막, 자를 구간만 정한다. 버튼 이름은 2026-11-23 화면 기준.

## 녹화 전 확인

1. 배포 주소의 `/api/health`를 연다. `constellations`가 11(양자리 적용), `demoSessions`가 `ready`, `aiKey`가 `key set`인지 본다. `aiKey`가 `no key`면 AI 칸이 모두 기본값으로 나오므로 녹화를 미룬다. `aiProvider`·`aiModel`은 녹화 기록에 적고, 07장·[AI 활용내역](AI활용내역.md)에 적은 모델과 다르면 문서를 맞춘다.
2. 테이크마다 새 시크릿 창을 연다. 시작 안내, 메뉴 안내, 밤하늘 첫 안내 카드, 마음 짚기 권유는 브라우저마다 한 번만 나와서 리허설한 창에서는 장면 2·3이 나오지 않는다.
3. 모바일 크기로 찍는다. 휴대폰 화면 녹화나 브라우저 개발자 도구의 기기 모드(예: 390×844)를 쓰고, 에뮬레이션이면 녹화 기록에 적는다.
4. 배경음악은 켠 채로 녹화한다. 새 창에서는 처음부터 켜져 있고 첫 터치 때 나오기 시작한다(위쪽 **음악** 버튼이 켜진 상태인지 확인). 곡(Kiss the Sky · Aakash Gandhi)은 출처 표시가 필요 없는 곡으로 [외부 자원과 출처](외부자원과_출처.md)에 올려 두었다. 화면 소리도 함께 녹음되게 녹화 도구의 시스템·탭 소리를 켠다.
5. 체험 방식은 **실제 API 모드**. 예시 모드로 찍으면 날씨·추천·제안에 '예시' 꼬리표가 붙고 새로고침 장면이 서버 기록을 보여 주지 못한다.
6. 주소창 URL이 07장에 적을 URL과 같은지 확인하고, 북마크바·다른 탭·알림·개인 계정 표시는 화면에서 치운다.

## 장면별 콘티

### 0 여는 말 · 0:00–0:08

- 화면: 첫 화면 "오늘의 작은 시도가 별이 되는 곳"과 체험 방식 줄 "실제 API 모드 · 서버 세션에 기록해요". 이어서 **데모 시작**.
- 자막: "나란히 — 오늘 할 수 있는 한 걸음을 별에 담는 AI 퀘스트" / "가상 사용자 민수(26)의 하루예요. 입력은 모두 가상이에요."
- 편집: **바꾸기** → **실제 API 모드**를 고르는 동작은 잘라도 된다. 대신 '실제 API 모드' 줄이 1초 이상 보이게 남긴다.

### 1 시작 질문 · 0:08–0:28

- 화면: ① 집 근처 → ② 사람 만나기 → ③ 혼자 하고 싶어요 → **저장하고 시작하기**.
- 자막: "어디까지 해 볼지는 내가 정해요." / "모든 질문은 건너뛸 수 있어요."
- 편집: 자르지 않는다. 세 답을 고르는 순간이 모두 보이게.

### 2 첫 별 4개 → 별마중 · 0:28–0:48

- 화면: **첫 별 따러 가기** → 첫 별 '숨 한 번 편하게 고르기'의 **하늘의 별 따기** → 2~4번 별(세 번째 별에서 한 줄 "창밖이 생각보다 밝았어요") → 별마중 모달 → **계속하기** → **다음** → **내 밤하늘 열기**.
- 자막: "별 하나는 작은 일 하나예요. 첫 별 네 개는 실패할 수 없어요." / (모달) "양자리를 완성하고 첫 친구 별마중을 만났어요. 딴 별은 실제 기록으로 남아요."
- 편집: 첫 별은 제 속도로 보여 준다. 2~4번은 빨리 감고, 그동안 화면 구석에 '▶▶ 빨리 감기'를 표시한다. 별마중 모달은 제 속도로 3초 이상 남긴다. "준비됐나요?" 장은 짧게.

### 3 메뉴 안내 · 0:48–0:53

- 화면: 밤하늘이 반짝이며 생기는 연출 → 메뉴 안내 1/4 오늘의 별, 2/4 도움받을 곳.
- 자막: "힘들 때 연락할 곳은 늘 위쪽 모서리에 있어요."
- 편집: 3/4 이후와 "하늘을 끌어서 둘러보세요" 카드를 닫는 동작은 자른다.

### 4 오늘의 별 추천 · 0:53–1:23

- 화면: 캐릭터 누르기 → 한 줄 "오늘은 집 근처까지는 나갈 수 있을 것 같아요." → **집 근처** → **마음 날씨 보기** → 마음 날씨 카드 → **오늘의 별 추천받기** → 추천 카드(산책로 한 바퀴 돌기)의 추천 이유 → **이 별과 만나 보기**.
- 자막: "오늘의 한 줄과 오늘 갈 수 있는 범위를 남겨요." / "한 줄을 마음 날씨로 빗대 봐요. 다르면 내가 옮길 수 있어요." / "오늘 고른 '집 근처'에 맞춰 오늘의 별을 추천해요."
- 자를 곳: 글자를 치는 동안(빈 칸에서 다 쓴 한 줄로 바로), "저장 중…"부터 날씨 카드가 뜨기 직전까지, 추천을 기다리는 동안, 마음 짚기 권유의 **나중에 할래요**.
- 남길 곳: 다 쓴 한 줄과 '집 근처'가 함께 보이는 프레임 1초 이상, 날씨 카드의 꼬리표('AI가 고른 날씨' 또는 '기본 날씨')와 "진단이 아닌 참고 기록이에요" 줄, 추천 목록 위 안내 줄("AI가 만든 추천은 틀릴 수 있어요." 또는 "기본 추천이에요."), 추천 이유 전문.

### 5 손 뻗어 보기 → 다음 별 · 1:23–1:53

- 화면: **손 뻗어 보기** → **몸·마음이 힘들었어요** → 한 줄 "산책로 입구까지만 가 봤어요." → **손 뻗은 별로 담기** → "손을 뻗은 별로 남았어요" → **다음으로 이어볼 별 찾아보기** → 제안 목록 → **오늘은 여기서 마칠래요**.
- 자막: "산책로 입구까지만 갔어요. 다 채우지 못해도 손을 뻗은 별로 남아요." / "어려웠던 이유를 고르면 다음 별을 고를 때 참고해요." / "오늘은 여기서 마쳐도 괜찮아요."
- 편집: 흐름은 자르지 않는다. 글자 입력과 "기록을 담는 중…"·"이어볼 별을 찾고 있어요…" 대기가 길 때만 그 구간을 줄인다.
- 남길 곳: 결과의 응원 문구와 "AI가 만든 응원은 틀릴 수 있어요." 줄, 제안 위 안내 줄("AI의 제안이에요. 다른 선택을 해도 괜찮아요." 또는 "기본 규칙으로 고른 제안이에요."), 별자리 이름과 '우선 제안' 꼬리표, 마친 뒤 "오늘의 기록은 그대로 남아요."

### 6 새로고침 → 별 회고 · 1:53–2:08

- 화면: **내 밤하늘에서 보기** → 방금 별의 기억 창(손을 뻗은 별 · 날짜 · 원문) → 브라우저 새로고침 → "밤하늘을 준비하고 있어요…" → 같은 기억 창이 다시 열림.
- 자막: "새로고침해도 오늘 어디까지 가 봤는지가 남아요." / "날짜와 내가 쓴 한 줄 그대로예요."
- 편집: 새로고침 전 기억 창부터 다시 열린 창까지 한 컷으로 둔다. 빨리 감기도 하지 않는다. 기록이 실제로 남는다는 걸 보여 주는 장면이다.
- 찍는 법: 주소창과 새로고침 버튼이 화면에 들어오게 찍는다. 개발자 도구 기기 모드로 기기 화면만 찍고 있다면 이 장면만 브라우저 창 전체를 찍거나, 적어도 "밤하늘을 준비하고 있어요…"가 보이는 순간을 남긴다. 휴대폰은 브라우저 메뉴의 새로고침을 쓴다.

### 7 청년센터 · 2:08–2:38

- 화면: 오른쪽 위 **청년센터·정책** → **청년센터** → **센터 자세히 보기** → 궁금한 점 "처음인데 예약 없이 들러도 되나요?" → **문의 초안 준비하기** → 초안 → **초안만 저장하기** → **앞까지 가 본 별 기록하기** → **하늘의 별 따기** → 한 줄 "센터 앞까지 갔는데 문을 열기는 어려웠어요." → **별 따서 담기** → "별을 땄어요".
- 자막: "센터 앞까지 갔다가 돌아온 날." / "처음 물어볼 문장을 미리 준비해 둬요. 앱에서 보내지는 않아요." / "센터 앞까지 간 것도 따로 별로 남아요." / "화면의 센터는 시연용 가상 센터예요."
- 자를 곳: 화면이 넘어가는 대기, 글자 입력, "준비 중…" 대기, 스크롤.
- 남길 곳: '가상 센터 · 실제 장소와 운영 정보가 아니에요' 꼬리표, "운영시간: 확인된 정보가 없어요", "앱에서 실제로 전송하지 않아요", 저장 뒤 "수정한 초안을 저장했어요. 실제로 전송하지 않았어요.", 앞까지 가 보기 카드의 "가상 장소의 시연이에요.". 초안이 기본 문장이면 "기본 문장으로 초안을 준비해 저장했어요."도 남긴다.

### 8 마무리 · 2:38–2:45

- 화면: 장면 7의 "별을 땄어요" 결과, 또는 **내 밤하늘에서 보기**로 돌아간 밤하늘.
- 자막: "다 해내지 않아도 괜찮아요. 손을 뻗은 순간도 하늘에 남아요." / "프로필의 '마음 짚기'로 4주마다 마음의 변화를 돌아볼 수도 있어요. 진단이 아닌 기록이에요."

## 편집 원칙

- 새 시크릿 창 하나에서 처음부터 끝까지 이어 찍은 녹화본 하나에서만 자른다. 다른 테이크의 장면을 섞지 않는다. 섞으면 새로고침 뒤에 남은 기록이 같은 세션의 것인지 보장할 수 없다.
- AI 기본 응답이 나온 장면을 다른 테이크의 AI 응답으로 바꾸지 않는다. 기본 응답이 나오면 꼬리표가 보이게 그대로 쓰고 자막도 화면에 맞추거나, 새 창에서 처음부터 다시 찍는다.
- 자막은 화면에 보이는 것만 말한다. 화면에 '기본 추천이에요'가 보이는데 "AI가 추천했어요"라고 쓰지 않는다.
- 화면 위에 없는 버튼·알림·데이터를 덧그리지 않는다. 장소·운영시간·문의 전송을 꾸며내지 않는다.
- 가상 시연 기록을 실제 효과 수치처럼 보이게 하는 자막(사용자 수, 개선율 등)은 넣지 않는다.
- 배경음악: 자른 곳마다 음악이 끊겨 튀면, 녹화된 소리를 끄고 같은 파일(`web/public/audio/kiss-the-sky.mp3`)을 편집 프로그램에서 영상 전체에 깔아도 된다. 곡이 약 2분 25초라 끝부분은 앱처럼 처음부터 다시 이어 붙이거나 페이드아웃한다. 내레이션을 넣으면 그 구간은 음악을 낮춘다.
