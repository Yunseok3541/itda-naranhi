# 별자리 기억 앨범
실제 모드는 기존 세션과 DATABASE_URL을 사용한다. 기존 DB에는 배포 전에 db/migrations/20261125_memory_photos.sql을 적용한다. 새 DB는 db/init/01_schema.sql에 포함되어 있다. 서버에서 크기를 제한해 JPEG로 다시 인코딩하고 PostgreSQL의 비공개 bytea 열에 보관한다. 조회와 삭제는 세션 사용자에게만 허용한다. 사진 삭제 시 재시도 식별자는 남겨 중복 기록을 방지한다.

예시 모드는 기존 별 기록과 사진을 같은 브라우저 저장 연산으로 저장한다. 브라우저 용량을 초과하면 사진을 빼거나 기존 사진을 삭제하고 다시 저장할 수 있다.
