## 1. 흐름

```
시작 질문 3개 → 내가 고른 답 → [다음]
  → 시작 안내 4장 (언제든 "건너뛰기")
     ① 환영: 나란히가 어떤 곳인지, 이번 안내에서 볼 것 3가지
     ② 연습 별자리: 아주 쉬운 연습 별 3개를 직접 "하늘의 별 따기" → 세 별이 이어져 별자리 완성 → 그날의 기억 카드
     ③ 별자리 친구: 별자리의 별을 모두 따면 그 친구를 도감에서 만남 (아직 못 만난 친구는 실루엣)
     ④ 하루 한 줄: 오늘의 별 = 한 줄 기록 → 마음 날씨 → 오늘의 별, 포인트가 쌓이는 방법, 매일 안 와도 된다는 안내
  → [내 밤하늘 열기] → 메인 위에 메뉴 한 장 안내 (실제 버튼에 점선 테두리 + 한 줄 설명)
  → 닫으면 기존 첫 안내 카드(하늘 끌기 → 별 누르기 → 별똥별)가 이어서 나옴
```

- 연습 별 3개: ① 숨 한 번 크게 쉬기 ② 지금 마음에 가까운 날씨 고르기(안 골라도 됨) ③ 오늘을 기억할 한 줄(비워 둬도 됨). 버튼을 누르면 무조건 별을 땀 → 실패·포기할 거리가 없음
- 다시 보기: 프로필 → ⚙ 설정 → 맨 아래 "나란히 사용 안내 다시 보기" (`/sky?guide=1`)

## 2. 제안 검토: 기획과 맞춘 부분

| 제안 | 결정 | 이유 |
| --- | --- | --- |
| 세계관 소개 | **반영**. 문구는 기획의 말투로 ("내 속도로", "다 해내지 않아도 괜찮아요") | "새로운 관계를 만들어 가게 됩니다"는 참여를 정해 주는 말이라, 참여는 사용자가 고른다는 원칙(v4 2장)에 맞춰 "원할 때 천천히 이어 갈 수 있어요"로 |
| 튜토리얼 퀘스트 3개 → 별자리 완성 | **반영** (직접 해 보기) | 첫 별은 실패할 수 없을 만큼 쉬워야 함(v4 7장). 퀘스트는 앱 안에서 바로 끝나는 일로만 |
| 완성한 별자리를 도감에 자동 등록 | **바꿈**: 연습 별자리는 안내 안에서만 빛나고 기록에 남기지 않음 | 도감 친구는 실제 별자리 10개와 1:1. 가짜 완성 기록이 생기면 프로필의 "만난 별자리"·배지·포인트·효과 지표가 섞임 (v4 8장: 별 개수는 목표가 아님). 대신 ③장에서 실제로 친구를 만나는 방법을 보여 줌 |
| 도감은 퀘스트와 별개로 "장소·경험을 발견해 수집" | **바꿈**: 실제 규칙대로 "별자리의 별을 모두 따면 그 친구를 만나요" | 지금 앱에서 도감은 별자리 완성으로만 채워짐 (도감 화면 소개 문구와 같게). 수집을 숙제처럼 느끼지 않게 하자는 제안 취지는 살림: "서두르지 않아도 친구들은 계속 기다려요" |
| 데일리 퀘스트 완료 시 100점 | **바꿈**: "하루 첫 체크인 +100 · 별을 처음 따면 +10~40 · 별똥별 +1" | 앱에 "데일리 퀘스트"는 없고, 100점은 하루 첫 체크인에 줌 (`lib/points.ts`). 메인 포인트 안내 문구와 같은 표현 |
| "매일 새로운 퀘스트가 기다리고 있어요" | **바꿈**: "매일 오지 않아도 돼요. 연속 기록도, 감점도 없어요" | 연속 기록 압박 없음(#31, v4 알림 원칙). 페르소나는 "연속 기록이 끊기면 자책하고 삭제"한 사람 |
| 주요 버튼·메뉴 안내 | **반영**: 안내 카드가 아니라 메인 화면 위 한 장 코치마크로 | 버튼 설명은 실제 버튼 옆에서 보여야 기억함(기능발견성 ④·D). 참고 이미지처럼 한 장에 모두 |
| 여러 화면에 걸친 흐름 (10단계) | **줄임**: 4장 + 메뉴 한 장, 1분 안쪽, 장마다 건너뛰기 | 팀 조사에서 "여러 장짜리 소개 튜토리얼은 효과 없음"(NN/g 70명 연구). 그래서 짧게, 읽기보다 직접 해 보기, 언제든 건너뛰기로 위험을 줄임 |

지키는 것
- **도움받을 곳은 항상 보임**: 안내 중에도 위쪽 모서리 "도움받을 곳" 버튼 그대로 (v4 7장 안전장치). 메뉴 안내 첫 항목도 도움받을 곳
- **이미 쓰던 사람에게 갑자기 뜨지 않음**: 시작 질문을 처음 마친 사람에게만. 다시 시작해도 한 번 본 안내는 다시 나오지 않음
- **서버·DB 변경 없음**: 예시 모드·실제 API 모드 모두 같은 화면, 아무것도 저장하지 않음 (본 여부만 이 브라우저에 기억)

## 4. 확인한 것

- 새 사용자: 시작 질문 → 안내 4장(연습 별 3개 따기, 날씨 고르기, 한 줄 입력) → 메인 → 메뉴 안내 → 닫으면 "하늘을 끌어서 둘러보세요" 카드. 새로고침해도 다시 안 나옴
- 첫 장에서 건너뛰기 → 바로 메인 + 메뉴 안내, Esc로 닫힘
- 이미 쓰던 사람(모드만 저장): 메뉴 안내 없이 기존 첫 안내 그대로
- 체험 방식 다시 선택 → 다시 시작: 안내 없이 바로 "내 밤하늘 열기"
- 다시 보기: 설정 → 안내(마지막 단추 "밤하늘로 돌아가기", 위 단추 "닫기") → 메인 + 메뉴 안내
- 메뉴 안내 화면 크기 400×860, 375×667, 360×740, 430×932: 설명끼리·설명과 다른 버튼·카드가 겹치지 않음. 320×568: 번호 + 목록 방식
- 기존 기능 다시 확인: 별 상세 → 별 기록 화면 클릭, 다른 화면에 갔다 오면 펼친 것 닫힘, 정책 탭 전환 효과
- 타입 검사·린트·빌드 통과, 콘솔 오류 없음. 예시 모드로 확인 (실제 API 모드는 서버 호출이 기존과 같아 별도 확인 안 함), 실기기 미확인
